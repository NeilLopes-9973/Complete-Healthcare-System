# Complete Healthcare System

A comprehensive web-based healthcare management system built with Flask that integrates disease prediction, doctor appointments, blood donation management, and NGO health checkup coordination.

## Features

- **Disease Prediction**: AI-powered disease prediction based on symptoms
- **Doctor Appointments**: Schedule appointments with doctors based on speciality
- **Blood Donation**: Manage blood donation requests and blood bank
- **NGO Health Checkups**: Coordinate health checkup events with NGOs
- **User Management**: Separate interfaces for patients, doctors, and NGOs

## Technologies Used

- Python / Flask
- MySQL Database
- Machine Learning (LightGBM)
- HTML/CSS/JavaScript
- Bootstrap

## Setup Instructions

1. Clone the repository
2. Install requirements: `pip install -r requirements.txt`
3. Configure database in `main.py`
4. Run the application: `python main.py`
